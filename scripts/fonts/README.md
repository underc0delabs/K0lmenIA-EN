# Report fonts

The k0lmenIA HTML reports embed these fonts (in base64) so they look the same on any
machine and without internet access. They are the same ones used by https://k0lmena.com:

- `saira.woff2` — Saira (variable, weights 500–700), for titles.
- `inter.woff2` — Inter (variable, weights 400–600), for body text.
- `jetbrains-mono.woff2` — JetBrains Mono (variable, weights 400–700), for code, IDs, labels and aligned numbers.

License: SIL Open Font License 1.1 (`OFL-Saira.txt`, `OFL-Inter.txt`, `OFL-JetBrainsMono.txt`).
The same fonts are in `docs/assets/fonts/` for the website and the diagrams.
