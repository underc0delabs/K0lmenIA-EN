# Fuentes de los reportes

Los reportes HTML de k0lmenIA incrustan estas fuentes (en base64) para verse igual en cualquier
máquina y sin internet:

- `geist-latin-wght-normal.woff2` — Geist (variable, pesos 100–900), subconjunto latino (incluye acentos y ñ).
- `geist-mono-latin-wght-normal.woff2` — Geist Mono (variable), para código, IDs y números alineados.

Origen: paquetes `@fontsource-variable/geist@5.3.0` y `@fontsource-variable/geist-mono@5.3.0`
(Vercel, https://github.com/vercel/geist-font). Licencia: SIL Open Font License 1.1 (`OFL-Geist.txt`).
