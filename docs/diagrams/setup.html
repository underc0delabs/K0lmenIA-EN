k0lmenIA · Getting started

Install, set your tokens in the .env and start asking the agents for things

QARMY · Underc0de

1Get it running

A few minutes, only once

1
RequirementsPython 3.10+ · Node.js 20+ (22 LTS recommended) · VS Code + Claude Code (Claude account or Anthropic API). Optional: Java 8+ (JMeter), Docker (security), JDK + Android SDK or Xcode (mobile).
2
Clone the repository
git clone https://github.com/underc0delabs/k0lmenIA.git
cd k0lmenIA
3
Install the dependencies
pip install -r requirements.txt # Mac/Linux: pip3
npm install # installs k0lmena
4
Create your .env
cp .env.example .env # PowerShell: copy
Fill in only what you'll use (column 2).
5
Check that everything is ready
npm run doctor # says what's missing and how
6
Open Claude Code
code .
claude # asks you to sign in the 1st time
For extra browsers: cd tools/k0lmena · npx playwright install chromium firefox webkit

2Set tokens in the .env

A single file, at the root · never versioned · the agents never ask for tokens in the chat

App under test E2E, mappers, exploratory, visual
APP_URL=https://staging.your-app.com
APP_USER=… · APP_PASSWORD=…
BASEURL=(if empty, uses APP_URL)
API Newman, API suite, k6
API_BASEURL=https://api.your-app.com · API_TOKEN=<your-token>
Jira and Confluence atlassian connector (active)
OAuth from /mcp, or with a token:
ATLASSIAN_MCP_AUTHENTICATION=token
JIRA_BASE_URL · JIRA_EMAIL · JIRA_API_TOKEN
Test management scripts/management
MANAGEMENT_TOOL=xray-cloud | xray-dc | qtm4j | aio
MANAGEMENT_PROJECT=PROJ
Xray Cloud: XRAY_CLOUD_CLIENT_ID · XRAY_CLOUD_CLIENT_SECRET
Xray DC: XRAY_DC_URL · XRAY_DC_TOKEN
QMetry: QTM4J_API_KEY · AIO: AIO_API_TOKEN
Optional: ESTIMATION_FACTOR=1.3 (estimated time × 1.3)
App repository project-documenter
REPO_PROVIDER=github | gitlab | azure-repos | bitbucket
REPO_NAME=my-company/my-app · GITHUB_TOKEN · GITLAB_TOKEN
Azure DevOps azure-devops connector
ADO_ORGANIZATION · ADO_PAT · ADO_PROJECT
Databases and security
DB_CONNECTIONS=main + DB_MAIN_ENGINE · _HOST · _DATABASE · _USER · _PASSWORD
SECURITY_AUTHORIZED_URLS=https://staging.your-app.com
Email, languages, roles and notifications email, translator, permissions, Slack/Teams
MAILPIT_URL=http://localhost:8025
TRANSLATOR_LANGUAGES=en-US,es-AR,pt-BR
PERMISSIONS_ROLES=admin,operator + PERMISSIONS_<ROLE>_USER · _PASSWORD
SLACK_WEBHOOK_URL · TEAMS_WEBHOOK_URL · MONITORING_URLS
Mailpit: docker compose -f tools/mailpit/docker-compose.yml up -d
Optional connectors (Azure DevOps, Figma, GitHub, GitLab, Linear, ClickUp, monday, Asana, Trello, Notion, YouTrack, Shortcut, QMetry, AIO Tests, k0lmenaTMT, Appium): npm run connector -- activate <name>, restart Claude Code and check with /mcp. Use test credentials, never production ones.

If a fact is missing

The agent doesn't make it up: it returns "I need you to confirm" and Claude asks you.

Actions with side effects

Writing to a database, creating data in Jira/Xray or running load: always with your ok.
