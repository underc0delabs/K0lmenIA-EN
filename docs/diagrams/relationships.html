Agent vs. skill

The agent is who does the whole task; the skill is how a part is done, and several agents share it.

Script vs. tool

A script is the repo's own code for formatting and calculation; a tool is external testing software (k0lmena, Newman, ZAP).

MCP vs. tool

MCP connects Claude Code to an external system to read from or write to it; a tool runs from the terminal.

To grow

Adding a capability means adding a piece: an agent, a skill, a connector, a tool or a script (see ARCHITECTURE.md).
