A single configuration

The root .env: URLs, credentials, k0lmena and test management. Never committed.

Doesn't make things up

Searches Jira, Confluence and Figma; what it can't find is recorded as Missing information (MI-01) in every report.

Saves tokens

What repeats is automated once and runs with npm, with no agents.

Traceability

US-001 → TC-001 → @TC-001 → key in Xray/QMetry/AIO → result.
